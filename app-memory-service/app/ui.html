Zugriff auf den Memory-Service

Chat-uebergreifendes Gedaechtnis. /mcp spricht MCP (Bearer-Token), /api/* ist im LAN offen (kein Token).

Als MCP-Server einbinden (Claude Code)

claude mcp add --transport http memory https://memory.claude.int/mcp \
  --header "Authorization: Bearer <MEMORY_TOKEN>"

Token in /daten/docker/memory/.env (Notiz cred-memory-token).

REST-Endpunkte (LAN, ohne Token)

POST /api/searchSuche, JSON-Body {q,k,scope,type}
GET /api/note?id=Volltext einer Notiz
POST /api/noteAnlegen; mit id = Update in place; supersedes = umbenennen
DELETE /api/note?id=Loeschen (git-recoverable)
GET /api/toolsDiese Tool-Liste
POST /api/reindexIndex neu bauen
GET /api/access · /api/stats · /healthzLog · Bestand · Status

cURL

# Suchen
curl -sk -X POST -H 'Content-Type: application/json' \
  -d '{"q":"frage in natuerlicher sprache","k":10}' \
  https://memory.claude.int/api/search

# Volltext
curl -sk 'https://memory.claude.int/api/note?id=<id>'

# Anlegen / Aktualisieren (id = Update)
curl -sk -X POST -H 'Content-Type: application/json' \
  -d '{"id":"gotcha-...","title":"...","summary":"<120 Zeichen","body":"...","type":"gotcha","scope":"homelab","tags":["..."]}' \
  https://memory.claude.int/api/note

# Loeschen
curl -sk -X DELETE 'https://memory.claude.int/api/note?id=<id>'

# Tools ueber MCP (SSE)
curl -sk https://memory.claude.int/mcp -H 'Authorization: Bearer <MEMORY_TOKEN>' \
  -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
